## 目的

确认用户登录后重新加载页面不会丢失会话，并且退出登录会撤销会话。

## 前置条件

- 已存在一个非生产测试账户；
- 浏览器允许第一方 Cookie。

## 步骤

1. 使用测试账户登录。
2. 刷新浏览器页面。
3. 确认页面仍显示当前用户。
4. 点击退出登录。
5. 再次访问受保护的用户资料接口。

## 期望

- 刷新后显示同一用户；
- 退出后页面回到登录状态；
- 退出后的 Session 访问受保护接口返回 401。

## 需要记录

- 登录和刷新后的用户资料；
- 退出后的 HTTP 状态；
- Cookie 是否为 HttpOnly 和 SameSite=Strict。
