## 目的

确认首次访问的用户可以使用邮箱、昵称和符合要求的密码创建账户。

## 前置条件

- 使用独立的测试邮箱；
- 测试数据不属于生产环境。

## 步骤

1. 打开 Cynos 用户中心。
2. 切换到注册表单。
3. 输入昵称、邮箱（使用本 Run 标记前缀 `luowang-<runId>-`）和至少 12 个字符的密码。
4. 提交注册表单。
5. 删除账号前，通过受控只读的 Run 范围存储字段聚合记录本 Run 标记账户的密码字段格式（该聚合只返回计数，不返回密码或哈希）。
6. 从欢迎页删除当前测试账号，再用原邮箱和原密码尝试登录。

## 期望

- 页面显示欢迎信息；
- `GET /api/auth/status` 返回已登录用户；
- 数据库不保存明文密码：本 Run 标记账户的存储密码字段为 Argon2id PHC 哈希格式，受控只读聚合只返回格式计数，不覆盖其他表或历史数据；
- 验证完成后可从欢迎页删除当前测试账号，原邮箱密码随后不能再登录。

## 需要记录

- 注册请求的结果；
- 删除前受控只读 Run 范围聚合返回的格式计数（accounts/argon2id/other）与 `cache-control`，记录中不得包含密码或哈希；
- 页面展示的用户昵称；
- 会话恢复结果；
- 删除账号后的页面提示和重新登录失败结果。
- 本 Run 标记数据的登记结果，以及 Run 结束后独立查剩余为 0、其他 Run 数据不受影响的清理核验结果。
