### 期望 C：退出后的 Session 访问受保护接口返回 401 —— **failed（已确认产品缺陷）**

## 3. 已确认产品缺陷（C）

- **预期**（场景原文 + 规格 `docs/changes/cynos-website-auth/spec.md` 行为 6/5）：退出登录撤销当前 Session；退出后的 Session 访问受保护接口返回 401。
- **实际**：退出（页面已回到登录态并提示“已安全退出”）之后，浏览器对受保护接口的请求被服务端按已登录处理，返回 200 与完整用户资料（`page-…12-09-29-769Z.yml`）。
- **复现条件**：非生产沙箱 `followup2-defect:3100`，固定 target；测试账号登录 → 重新加载确认登录态 → 退出（页面回登录表单）→ 同一浏览器上下文再访问受保护接口。可复现材料：`page-…12-09-26-300Z.yml`（退出后）→ `page-…12-09-29-769Z.yml`（退出后仍返回资料）。
- **影响**：退出登录未能使服务端会话失效，登出在服务端的撤销语义未达成（同一会话在退出后仍可读取用户资料）。本轮不判定线上影响范围，也不归因到具体改动（无 base commit）。
- 关联：与既有 issue #5 同源；未创建新 Issue。标题如需使用“非生产沙箱验收”口径。
