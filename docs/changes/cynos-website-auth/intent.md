# 意图

## 问题

LuoWang Phase 2 需要一个独立、可清理、可观察的真实测试项目，不能把场景资产和测试分支放入 LuoWang 自己的仓库。测试项目还需要有足够明确的业务行为，供后续阶段执行浏览器场景。

## 期望结果

建立一个 Cynos 官网样例，用户可以注册、登录、退出，并在刷新后恢复登录状态。该行为应由真实服务端、SQLite 和安全 Session 实现，而不是只在前端伪造状态。

## 影响与约束

- 项目独立托管在 `cynos-ai/cynos-website`；
- 遵循 Cynos 默认文档和场景目录约定；
- 只使用非生产测试数据；
- 不把账号密码、Token 或其他 Secret 写入项目文件。

## 非目标

本变更不实现邮箱验证、密码找回、OAuth、复杂 RBAC、生产部署或支付功能。
